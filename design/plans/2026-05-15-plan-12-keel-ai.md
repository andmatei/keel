# keel-ai: Claude Code Plugin — Implementation Plan (Phase 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Phase 1 keel-ai Claude Code plugin: config model validation, CLAUDE.md generation (SessionStart hook + skill), and the lifecycle-aware /design-sync skill.

**Architecture:** The plugin has two halves. The Python side adds `[extensions.ai]` config models and two `keel ai` subcommands to keel-cli. The Claude Code plugin side (`plugins/keel-ai/`) provides the SessionStart hook (calls `keel ai generate-claude-md`), skills (/design-sync, /generate-claude-md), and a design-sync agent. The SessionStart hook generates a CLAUDE.md at the project root as the instruction channel between keel and Claude Code.

**Tech Stack:** Python 3.11+ (Pydantic v2, Typer), Bash (hook scripts), Markdown (skills/agents)

**Test baseline:** 632 keel-cli tests passing. Version bump: keel-cli 0.0.6 → 0.0.7.

# src/keel/ai/config.py
"""Pydantic models for `[extensions.ai]` in project.toml."""

from __future__ import annotations

from typing import Any

from pydantic import BaseModel, ConfigDict, Field


class TriggerWhen(BaseModel):
    """Optional condition filter on a trigger — matches event payload fields."""

    model_config = ConfigDict(extra="forbid", populate_by_name=True)

    to: str | None = None
    from_state: str | None = Field(None, alias="from")


class Trigger(BaseModel):
    """A single trigger mapping a keel event to an AI action."""

    model_config = ConfigDict(extra="forbid")

    event: str
    when: TriggerWhen | None = None
    action: str
    mode: str | None = None
    enabled: bool = True


class AISkills(BaseModel):
    """Skill routing — which skill handles each workflow phase."""

    model_config = ConfigDict(extra="forbid")

    scope: str = "writing-scopes"
    design: str = "writing-tech-designs"
    plan: str = "superpowers:writing-plans"


class ClaudeMdConfig(BaseModel):
    """Configuration for CLAUDE.md generation."""

    model_config = ConfigDict(extra="forbid")

    extra: str | None = None


class AIConfig(BaseModel):
    """Top-level schema for [extensions.ai] in project.toml."""

    model_config = ConfigDict(extra="forbid")

    enabled: bool = True
    triggers: dict[str, Trigger] = Field(default_factory=dict)
    skills: AISkills = Field(default_factory=AISkills)
    claude_md: ClaudeMdConfig = Field(default_factory=ClaudeMdConfig)


def parse_ai_config(raw: dict[str, Any] | None) -> AIConfig:
    """Parse and validate an [extensions.ai] dict. Returns defaults if raw is None or empty."""
    if not raw:
        return AIConfig()
    return AIConfig.model_validate(raw)
```

# src/keel/commands/ai/show_config.py
"""`keel ai show-config` — parse and display [extensions.ai] configuration."""

from __future__ import annotations

import typer
from pydantic import ValidationError

from keel.api import ErrorCode, Output, load_project_manifest, resolve_cli_scope
from keel.ai.config import parse_ai_config


def cmd_show_config(
    ctx: typer.Context,
    project: str | None = typer.Option(
        None, "--project", "-p", help="Project name. Auto-detected from CWD."
    ),
    json_mode: bool = typer.Option(False, "--json", help="Emit JSON to stdout."),
) -> None:
    """Show the validated [extensions.ai] configuration for a project."""
    out = Output.from_context(ctx, json_mode=json_mode)

    scope = resolve_cli_scope(project, None, out=out)
    pm = load_project_manifest(scope.manifest_path)
    raw = pm.extensions.get("ai", {})

    try:
        config = parse_ai_config(raw)
    except ValidationError as e:
        out.fail(
            f"invalid [extensions.ai] config: {e}",
            code=ErrorCode.INVALID,
        )

    payload = config.model_dump(by_alias=True)

    if json_mode:
        out.result(payload)
        return

    out.info(f"AI extension: {'enabled' if config.enabled else 'disabled'}")
    if config.triggers:
        out.info(f"Triggers: {len(config.triggers)}")
        for name, trigger in config.triggers.items():
            status = "" if trigger.enabled else " (disabled)"
            out.info(f"  {name}: {trigger.event} → {trigger.action}{status}")
    else:
        out.info("Triggers: none configured")
    out.result(payload, human_text="")
```

# src/keel/ai/claude_md.py
"""Generate CLAUDE.md content from project state."""

from __future__ import annotations

from pathlib import Path

from keel.ai.config import parse_ai_config
from keel.manifest import (
    load_milestones_manifest,
    load_project_manifest,
)
from keel.workspace import Scope, deliverable_dir, read_phase


def generate_claude_md(scope: Scope) -> str:
    """Generate CLAUDE.md content for a project scope.

    Reads project manifest, milestones, deliverables, and AI config
    to produce a markdown document that serves as Claude Code's
    instruction set for this project.
    """
    pm = load_project_manifest(scope.manifest_path)
    phase = read_phase(scope.unit_dir)
    ai_config = parse_ai_config(pm.extensions.get("ai"))

    lines: list[str] = []

    _header(lines, pm.project.name, phase, pm.project.lifecycle)
    _artifacts(lines, scope)
    _deliverables(lines, scope)
    _active_work(lines, scope)

    if ai_config.enabled and ai_config.triggers:
        _workflow(lines, ai_config)

    if ai_config.claude_md.extra:
        _extra(lines, scope.unit_dir, ai_config.claude_md.extra)

    return "\n".join(lines) + "\n"


def _header(lines: list[str], name: str, phase: str, lifecycle: str) -> None:
    lines.append(f"# Project: {name}")
    lines.append(f"# Phase: {phase}")
    lines.append(f"# Lifecycle: {lifecycle}")
    lines.append("")


def _artifacts(lines: list[str], scope: Scope) -> None:
    lines.append("## Artifacts")
    _artifact_line(lines, "Scope", scope.scope_md_path)
    _artifact_line(lines, "Design", scope.design_md_path)

    decisions = (
        sorted(scope.decisions_dir.glob("*.md"))
        if scope.decisions_dir.is_dir()
        else []
    )
    if decisions:
        rel = _rel(scope.decisions_dir, scope.unit_dir)
        lines.append(f"- Decisions: {rel} ({len(decisions)} files)")

    mm = load_milestones_manifest(scope.milestones_manifest_path)
    if mm.milestones:
        counts: dict[str, int] = {}
        for m in mm.milestones:
            counts[m.status] = counts.get(m.status, 0) + 1
        summary = ", ".join(f"{c} {s}" for s, c in counts.items())
        lines.append(f"- Milestones: milestones.toml ({summary})")

    lines.append("")


def _artifact_line(lines: list[str], label: str, path: Path) -> None:
    if path.is_file():
        lines.append(f"- {label}: {path.name}")
    else:
        lines.append(f"- {label}: *(not yet created)*")


def _deliverables(lines: list[str], scope: Scope) -> None:
    deliv_root = scope.unit_dir / "deliverables"
    if not deliv_root.is_dir():
        return

    entries: list[tuple[str, str, Scope]] = []
    for child in sorted(deliv_root.iterdir()):
        if not child.is_dir():
            continue
        manifest_path = child / "project.toml"
        if not manifest_path.is_file():
            continue
        d_phase = read_phase(child)
        d_scope = Scope(project=scope.project, deliverable=child.name)
        entries.append((child.name, d_phase, d_scope))

    if not entries:
        return

    lines.append("## Deliverables")
    for name, d_phase, d_scope in entries:
        lines.append(f"- **{name}** ({d_phase} phase)")
        if d_scope.scope_md_path.is_file():
            lines.append(f"  - Scope: deliverables/{name}/scope.md")
        if d_scope.design_md_path.is_file():
            lines.append(f"  - Design: deliverables/{name}/design.md")
    lines.append("")


def _active_work(lines: list[str], scope: Scope) -> None:
    mm = load_milestones_manifest(scope.milestones_manifest_path)
    active_milestones = [m for m in mm.milestones if m.status == "active"]
    if not active_milestones:
        return

    lines.append("## Active Work")
    for milestone in active_milestones:
        m_tasks = [t for t in mm.tasks if t.milestone == milestone.id]
        done_count = sum(1 for t in m_tasks if t.status == "done")
        lines.append(
            f"- Milestone {milestone.id} \"{milestone.title}\" "
            f"(active, {done_count}/{len(m_tasks)} tasks done)"
        )
        for t in m_tasks:
            if t.status in ("active", "planned"):
                lines.append(f"  - Task {t.id} \"{t.title}\" ({t.status})")
    lines.append("")


def _workflow(lines: list[str], ai_config) -> None:
    lines.append("## AI Workflow")
    for name, trigger in ai_config.triggers.items():
        if not trigger.enabled:
            continue
        instruction = _trigger_instruction(trigger)
        lines.append(f"- {instruction}")
    lines.append("")


def _trigger_instruction(trigger) -> str:
    """Convert a trigger config into a human-readable instruction."""
    event_desc = trigger.event.replace(".", " ").replace("post", "").strip()
    when_desc = ""
    if trigger.when:
        parts = []
        if trigger.when.to:
            parts.append(f"to={trigger.when.to}")
        if trigger.when.from_state:
            parts.append(f"from={trigger.when.from_state}")
        if parts:
            when_desc = f" (when {', '.join(parts)})"

    mode_desc = f" --{trigger.mode}" if trigger.mode else ""
    return f"After {event_desc}{when_desc}: run /{trigger.action}{mode_desc}"


def _extra(lines: list[str], unit_dir: Path, extra_path: str) -> None:
    full = unit_dir / extra_path
    if full.is_file():
        lines.append(full.read_text().rstrip())
        lines.append("")


def _rel(path: Path, base: Path) -> str:
    """Relative path for display."""
    try:
        return str(path.relative_to(base))
    except ValueError:
        return str(path)

# src/keel/commands/ai/generate_claude_md.py
"""`keel ai generate-claude-md` — generate CLAUDE.md from project state."""

from __future__ import annotations

from pathlib import Path

import typer

from keel.ai.claude_md import generate_claude_md
from keel.api import Output, resolve_cli_scope


def cmd_generate_claude_md(
    ctx: typer.Context,
    project: str | None = typer.Option(
        None, "--project", "-p", help="Project name. Auto-detected from CWD."
    ),
    output: Path | None = typer.Option(
        None, "--output", "-o", help="Write CLAUDE.md to this path instead of stdout."
    ),
    json_mode: bool = typer.Option(False, "--json", help="Emit JSON to stdout."),
) -> None:
    """Generate a CLAUDE.md from the project's current state and AI config."""
    out = Output.from_context(ctx, json_mode=json_mode)

    scope = resolve_cli_scope(project, None, out=out)
    content = generate_claude_md(scope)

    if output is not None:
        output.write_text(content)

    if json_mode:
        payload = {"content": content}
        if output is not None:
            payload["path"] = str(output)
        out.result(payload)
    elif output is not None:
        out.result(None, human_text=f"Wrote CLAUDE.md to {output}")
    else:
        out.result(None, human_text=content)

# keel-ai SessionStart hook
# 1. Generate/update CLAUDE.md at the project root.
# 2. Output the using-keel-ai skill as additional session context.
set -euo pipefail

PLUGIN_ROOT="${CLAUDE_PLUGIN_ROOT:-$(cd "$(dirname "$0")/.." && pwd)}"

# Check if keel CLI is available.
if ! command -v keel &>/dev/null; then
    exit 0
fi

# Check if we're inside a keel project (keel show --brief --json succeeds).
if ! keel show --brief --json 2>/dev/null | grep -q '"name"'; then
    exit 0
fi

# Generate CLAUDE.md at the project root.
# Use --output to write the file; stderr goes to /dev/null to keep hook clean.
PROJECT_ROOT=$(keel show --brief --json 2>/dev/null | python3 -c "import sys,json; print(json.load(sys.stdin)['path'])" 2>/dev/null || echo "")
if [ -n "$PROJECT_ROOT" ]; then
    keel ai generate-claude-md --output "$PROJECT_ROOT/CLAUDE.md" 2>/dev/null || true
fi

# Read the using-keel-ai skill and output as additional context.
SKILL_FILE="$PLUGIN_ROOT/skills/using-keel-ai/SKILL.md"
if [ ! -f "$SKILL_FILE" ]; then
    exit 0
fi

# Read skill content, strip frontmatter.
SKILL_CONTENT=$(awk '/^---$/{if(++c==2){found=1;next}}found' "$SKILL_FILE")

# Escape for JSON.
ESCAPED=$(printf '%s' "$SKILL_CONTENT" | python3 -c "
import sys, json
print(json.dumps(sys.stdin.read()), end='')
" 2>/dev/null || printf '""')

# Output in Claude Code hook format.
printf '{"hookSpecificOutput":{"hookEventName":"SessionStart","additionalContext":%s}}\n' "$ESCAPED"

You review a project's implementation state and compare it against the
design documents. Your job: find drift and either fix it or report it.

## Input

You will receive:
- **mode**: `lightweight`, `thorough`, or `check`
- **scope**: project name and optional deliverable

## Process

### 1. Read project state

```bash
keel show <project> --json
keel ai show-config --json --project <project>
```

Read the design documents:
- `scope.md` — boundaries and goals
- `design.md` — current technical approach
- `decisions/*.md` — past decisions
- `.keel/phase` — current phase

### 2. Read implementation state

Check code worktrees for recent changes:
```bash
git log --oneline -20  # in each worktree
git diff --stat HEAD~5  # recent changes
```

Read milestone/task state:
```bash
keel milestone list --json --project <project>
keel task list --json --project <project>

### 3. Compare and identify drift

For each section of design.md, check:
- Does the implementation match what was designed?
- Were there decisions made during implementation that aren't recorded?
- Are there open questions in the design that have been answered by the code?
- Did the scope change implicitly (features added/removed)?

### 4. Mode-specific behavior

**lightweight** (after task completion):
- Focus on the area the completed task touched
- Read the task's diff (files changed)
- Apply targeted updates to design.md
- Small, focused changes — not a full rewrite

**thorough** (after milestone completion):
- Review all changes across the milestone's tasks
- Full design.md review: architecture, components, data flow, API surface
- Update decisions/ if implicit decisions were made
- Flag scope drift: "Implementation added X not in scope.md"

**check** (report only):
- Produce a drift report but make no edits
- Present findings and ask the user what to update

### 5. Output

**For lightweight and thorough modes:**
- Edit design documents directly
- Commit changes with message: `docs: design-sync (<mode>) after <context>`
- Report what was changed

**For check mode:**
Summarize as:
- **Aligned**: what matches the design
- **Drifted**: what diverges (and how)
- **Missing from design**: built but not designed
- **Missing from code**: designed but not built
- **Decisions to record**: implicit decisions

Lead with what drifted, not with what's aligned. Keep it concise.

### 6. Guardrails

- In lightweight/thorough mode: edit design.md and decisions/ only. Never edit scope.md — flag scope drift for the user to decide.
- Never remove content from design.md. Update, add, or mark as outdated.
- If you're unsure about a change, flag it in check mode instead of editing.
